# LS ITC 취업규칙 요약 (LSI-20-01, 2025.02.23 기준)

## 1장. 총칙

- **목적**: 사원의 취업조건·복무규율을 정해 직장 질서 유지 및 복리증진
- **적용범위**: 회사 사업장에 근무하는 전 사원
- **사원 정의**: 제2장에 의해 임용된 자

---

## 2장. 인사

### 직급 구분 (제6조)
| 직급 | 호칭 | 표준 체류연한 |
|------|------|---------------|
| 수석 | 수석 | - |
| 책임Ⅱ / 책임 | 책임 | 5년 |
| 선임 | 선임 | 4년 |
| 주임 / 사원Ⅱ | 주임 | 4년 (전문대졸 3년) |
| 사원 | - | 고졸 6년 |

### 임용·수습 (제8~11조)
- 신규 임용자는 3개월 이내 수습기간 적용
- 수습기간 중 성적 불량 시 임용 취소 가능
- 수습기간 중 급료: 초임급의 **90%** 지급

### 임용 제한 (제12조)
- 금고 이상 형 집행 종료 후 2년 미경과자
- 피성년후견인, 파산선고 후 복권되지 않은 자
- 불미스러운 소행으로 해직된 자 등

### 사직 및 면직 (제14~16조)
- 사직 희망 시 **퇴직일 30일 전** 사직원 제출
- 면직 예고: 회사도 30일 전 예고 의무 (미이행 시 30일분 통상임금 지급)

### 정년 (제17조)
- **만 60세** 도달하는 해의 마지막 날
- 일반직은 만 **56세부터 임금피크제** 실시

### 휴직 (제21조)
| 사유 | 기간 |
|------|------|
| 업무외 부상·질병 (1주 초과) | 최대 12개월 |
| 사사로운 사유 (1개월 초과) | 최대 1개월 |
| 병역 징집·동원 | 복무기간 |
| 기소 | 확정판결 시까지 |
| 육아휴직 | 자녀 1명당 최대 2년 (분할 최대 3회) |

- 육아휴직 대상: 만 8세 이하 또는 초등 2학년 이하 자녀
- 복직 후 동일 업무 또는 동등 수준 임금 직무 복귀 보장

## 3장. 복무

### 근무시간 (제35조)
- 1일 **8시간** (휴게시간 제외)
- 선택적 근로시간제·재량근로시간제 운영 가능

### 휴게시간 (제36조)
- 1일 **1시간** (식사시간 포함)

### 결근·지각·조퇴 (제39~41조)
- 결근 시 사전 결근계 제출 (긴급 시 사후 제출)
- 5일 이상 연속 결근 시 **의사 진단서** 첨부 필요
- 조퇴 시 사전 조퇴원 제출

### 휴일 (제43조)
- 주휴일
- 국가 공휴일 및 임시휴일
- 회사 지정 휴일

### 연차휴가 (제45조)
| 조건 | 부여일수 |
|------|----------|
| 1년간 80% 이상 출근 | **15일** |
| 1년 미만 또는 80% 미만 출근 | 1개월 개근 시 **1일** |
| 3년 이상 계속 근로 | 2년 초과 매 2년마다 **1일 가산** (최대 25일) |

- 연차 미사용 시 **1년 후 소멸**, 통상임금으로 보상
- 회사 귀책사유로 미사용 시 통상임금의 **150%** 지급
- 연차 계산 기준: 입사일 기준 (회계기준일 병행 가능)

### 출산·육아 관련 휴가
| 종류 | 내용 |
|------|------|
| 출산전후휴가 | 90일 (미숙아 100일, 쌍태아 120일), 산후 45일 이상 필수 |
| 배우자 출산휴가 | **20일 유급** (출산 후 120일 이내, 3회 분할 가능) |
| 난임치료휴가 | 연 6일 (최초 3일 유급) |
| 보건휴가 | 월 1일 무급 (여성 사원) |
| 육아시간 | 생후 1년 미만 아동: 1일 2회 각 30분 유급 수유시간 |
| 가족돌봄휴직 | 연 최장 90일 (1회 30일 이상) |
| 가족돌봄휴가 | 연 최장 10일 |

### 임신기 근로시간 단축 (제46조의9)
- 임신 후 **12주 이내** 또는 **32주 이후**: 1일 2시간 단축 가능

### 육아기 근로시간 단축 (제46조의10)
- 만 12세 이하 또는 초등 6학년 이하 자녀 양육 시 신청 가능
- 단축 후 근무시간: 주 **15~35시간**

### 연장·야간·휴일근로 (제60조)
- 연장근로: 주 최대 **12시간** 한도
- 야간근로(오후 10시~오전 6시): 18세 이상 여성은 본인 동의 필요

## 4장. 급여

### 급여 구조 (제81조)
- 월정급여 = 기본임금 + 제수당 (구성은 별도 규정)
- 급여일: 매월 정해진 날짜
- 수습기간 중: 초임급의 **90%**

### 휴업수당 (제79조)
- 회사 사정으로 휴업 시: 평균임금의 **70% 이상** 지급

### 상여금 (제89조)
- 종류와 지급기준은 별도 규정
- 지급 당시 재직자에 한해 지급

### 퇴직급여 (제91조)
- 퇴직급여 지급세칙에 따라 지급

---

## 5장. 재해보상

- **요양보상**: 업무상 부상·질병 시 요양비용 지급
- **휴업보상**: 요양 중 평균임금의 **70%** 지급
- 산업재해보상보험법에 의한 보험금 수령 시 중복 지급 없음

---

## 6장. 교육안전 및 보건

- 건강진단: 만 40세 미만 **2년 1회**, 만 40세 이상 **매년 1회**
- 성희롱 예방교육 실시 (세칙 별도)

---

## 7장. 상벌

### 징계의 종류 (제111조)
| 종류 | 내용 |
|------|------|
| 견책 | 시말서 제출 및 훈계 |
| 감급 | 1회 평균임금 1일분의 1/2 이내, 총액 임금 총액의 1/10 이내 |
| 정직 | 3개월 이내 출근 정지, 무급 |
| 강직 | 직위·직급 강하 |
| 권고사직 | 사직원 제출 후 퇴직 |
| 징계해고 | 예고 없이 즉시 해고 |

### 징계해고 주요 사유 (제113조)
- 입사 서류 허위 기재
- 직무 이용 사리 도모
- 회사 물건 절취·횡령·배임
- 유죄판결 확정
- 직장 내 괴롭힘·폭행·협박

### 금지사항 (제30조)
- 무허가 겸직 (경쟁업체 겸직·창업 금지, 퇴직 후 **2년간** 유지)
- 회사 기밀 누설 (재직 중·퇴직 후 모두 적용)
- 직장 내 괴롭힘 행위
